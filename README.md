# Namma HomeStay Premium

A premium rural homestay discovery and booking Android application built using Kotlin and Jetpack Compose.
Built with modern Android architecture.

## Features

- Premium dark UI
- Rural homestay listings
- Detail exploration screen
- Smooth navigation
- Luxury card-based interface
- Modern Android architecture
- Jetpack Compose UI
- Navigation Compose integration

## Tech Stack

- Kotlin
- Jetpack Compose
- Android Studio
- Navigation Compose
- Material 3

## Project Vision

Namma HomeStay helps users discover immersive rural travel experiences, eco-tourism destinations, and local homestays with a premium mobile experience.
